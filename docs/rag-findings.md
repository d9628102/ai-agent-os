# PSF EIM RAG 問答:實測結果與已知限制

記錄 `scripts/rag_answer.py` 在 GX10 上針對 `psf_eim_kb` 的實測結果。
測試集為 `scripts/data/psf-eim-qa-questions.txt`(5 題內容問題 + 1 題
負向對照)。

> **樣本數警告**:以下每種設定都只跑過**一次**。趨勢明確的項目(例如
> 耗時差異達 4.8 倍)可以採信,但涉及回答品質的細微差異(例如越界抑制
> 效果)在單次測試下**不足以下定論**,待補測見文末。

## 思考模式開關的 A/B 對比

同一組 6 題,`--no-think` 開關的差異:

| 問題 | 思考開啟 | 思考關閉 | 加速 |
|---|---|---|---|
| 五大產品矩陣 | 19.21s | 4.56s | 4.2× |
| Decision Matrix 核心模組 | 14.54s | 2.60s | 5.6× |
| 跟 ERP/CRM 的差異 | 31.12s | 9.44s | 3.3× |
| 負責客戶服務的 Agent | 17.19s | 1.56s | 11.0× |
| 架構分成幾層 | 15.10s | 3.20s | 4.7× |
| 定價(負向對照) | 14.65s | 1.89s | 7.8× |
| **平均端到端** | **18.63s** | **3.87s** | **4.8×** |

輸出 tokens 從 2379 降到 446 —— **約 81% 的生成量是使用者看不到的推理
內容**。tokens/s 兩者都在 16–22 之間,幾乎沒變,所以加速完全來自產出量
減少,不是吞吐提升。

耗時結構:**生成佔 99.8%**。embedding 約 0.03–0.05 秒、Qdrant 檢索約
0.00–0.01 秒,兩者相對於生成可以視為免費。要再壓低延遲只有從生成端下手。

## 正確性

兩種設定下,**5 題內容問題的事實全部正確**,沒有捏造任何 PSF 產品、模組
或 Agent 名稱。

**負向對照(定價)在兩種設定下都守住了** —— 都明確回答「文件中未提及」,
沒有編造價格。防幻覺的保護**不依賴思考模式**。

## 已知限制

1. **關閉思考模式時,涉及「命名易混淆」或「需列出完整組成清單」的問題,
   有機率遺漏辨析細節或列舉不完整。** 實測到的例子:
   - 思考開啟時,回答「負責客戶服務的 Agent」會主動釐清「Service Matrix
     底下的 Customer Success 是**模組**、不是 Agent」;關閉後直接給答案,
     沒有這層辨析。
   - 思考開啟時,回答「架構分幾層」會列出各層的組成元件;關閉後只列層級
     名稱,並自行補了文件中沒有的中文譯名(「企業層」「基礎架構矩陣」)。
   - 負向對照題在關閉後,沒有照 system prompt 要求說明「在文件裡找到什麼、
     為何不足以回答」,只說沒有定價資訊。

2. **加嚴後的 system prompt 對「越界」的抑制,單次測試下在思考開啟時
   更乾淨,但樣本數不足,待補測。** 越界指的是模型用自己的既有知識描述
   文件未提及的比較對象(例如描述 ERP/CRM 是做什麼的,而文件只寫了
   「PSF EIM 並不是 ERP、CRM」)。舊 prompt + 思考開啟時是三段式的結構化
   論述;新 prompt + 思考關閉時減到一句附帶說明,但性質相同、沒有完全消失。

3. **上述比較有混淆變因**:system prompt 加嚴與關閉思考模式是**同時**
   變更的,因此無法歸因 Q3 的改善來自哪一項。

## 目前的決定

**預設維持思考模式開啟**,`--no-think` 為 opt-in,等正式跑過多次重複
測試後再決定是否調整預設。

**試用期間的因應**:若同事回報「答案感覺沒講清楚」,可請他們在問題後
加註要求更詳細說明,或改用預設(思考開啟)重問。

## 待補測

- [ ] **去除混淆變因**:跑「新 prompt + 思考開啟」,與已有的「舊 prompt +
      思考開啟」「新 prompt + 思考關閉」三方對照,釐清越界改善的來源。
      指令即現行預設:
      `python3 scripts/rag_answer.py --queries-file scripts/data/psf-eim-qa-questions.txt`
- [ ] **多次重複測試**:同一組題目在同一設定下跑多次,觀察回答品質的
      變異程度,再決定是否把 `--no-think` 設為預設。
- [ ] **擴充負向對照**:目前只有「定價」一題。建議再加入幾題文件確實
      沒有的主題(例如導入時程、技術規格、競品比較),確認防幻覺不是
      對單一題型的巧合。
